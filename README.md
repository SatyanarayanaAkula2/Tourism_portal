🌍 Tourism Portal – MERN Stack Full-Stack Application

A modern full-stack tourism booking platform built using the MERN stack, allowing users to explore destinations, book travel packages, manage bookings, and access analytics dashboards with secure authentication and responsive UI.

🚀 Live Demo

### Frontend
[Frontend Url](https://yatrigo-towz.onrender.com)

### Backend
[Backend Url](https://tourism-portal-be.onrender.com)

## ✨ Features

- 🔐 JWT Authentication & Authorization
- 👤 User & Admin Roles
- 🏝️ Destination Exploration
- 📦 Package & Hotel Selection
- 🧾 Booking Management System
- 📊 User & Admin Analytics Dashboard
- 🌙 Dark / Light Theme
- 📱 Fully Responsive UI
- 🔍 Filtering & Pagination
- ⚡ Global Loaders & Error Handling
- 🛡️ Helmet, Rate Limiting & CORS Security
- ☁️ Cloud Deployment on Render


## 🛠️ Tech Stack

### Frontend
- React.js
- React Router
- Context API
- Axios
- CSS3

### Backend
- Node.js
- Express.js
- MongoDB
- JWT Authentication
- Mongoose

## ⚙️ Installation

### Clone Repository

bash
git clone [git repo url](https://github.com/SatyanarayanaAkula2/Tourism_portal)

## Frontend Setup

bash
cd tourism_portal_frontend
npm install
npm run dev

## Backend Setup

bash
cd Tourism_portal_backend
npm install
npm start

## 🔑 Environment Variables

Create .env files inside frontend and backend folders.

Example backend variables:

env
PORT=5000

MONGO_URI=your_mongodb_uri

JWT_SECRET=your_secret

CLIENT_URL=frontend url
